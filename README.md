2D Plotter using MATLAB, Python, and Arduino
Features:
- Image to G-code conversion
- Python-Arduino serial communication
- Belt-driven X-Y motion system
- Servo-controlled rack-and-pinion pen mechanism
- Coordinate scaling for accurate motion execution

Hardware:
- Arduino Uno R4 Minima
- A4988 Drivers
- NEMA 17 Stepper Motors
- Servo Motor
